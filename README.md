# Зерно и помол — Bootstrap-версия

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Дисциплина: «Фронтенд и бэкенд разработка».

## Описание

Проект — учебная версия интернет-магазина кофе и оборудования для заваривания,
сделанная на Bootstrap. Это отдельная реализация той же предметной области,
что и в контрольной работе №1, а не адаптация её кода: разметка построена
на сетке и компонентах фреймворка, собственный CSS только настраивает тему.

## Подключение Bootstrap

Bootstrap подключён локально, без CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JS Bundle с Popper,
  нужен для меню, выпадающего списка, модального окна, вкладок, accordion,
  карусели, offcanvas и toast.

Файлы взяты из официального архива compiled-версии
(https://getbootstrap.com/docs/5.3/getting-started/download/) и совпадают
с версией на CDN. Рядом лежат `.map`-файлы, чтобы DevTools показывал исходники.

Порядок подключения на каждой странице:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
...
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

`custom.css` идёт после Bootstrap, чтобы переопределять его стили;
`main.js` — после Bundle, потому что использует объект `bootstrap`.

## Bootstrap-сетка

- `container` — основное содержимое, `container-fluid` — полосы на всю ширину
  (верхняя строка шапки, фон hero-блока);
- `row` + адаптивные колонки:
  - `col-12 col-lg-6` — hero и страница товара;
  - `col-12 col-md-6 col-lg-3` — преимущества;
  - `col-6 col-lg-3` — категории;
  - `col-12 col-md-6 col-xl-4` — товары в каталоге;
  - `col-12 col-lg-3` + `col-12 col-lg-9` — каталог «фильтр + товары»;
  - `col-12 col-lg-8` + `col-12 col-lg-4` — заявка;
- промежутки `g-3`, `g-4`, `g-lg-5`;
- utility-классы: отступы `my-5`, `mb-3`, `p-4`, flex `d-flex`, `gap-2`,
  `justify-content-between`, цвета `bg-light`, `text-muted`, `shadow-sm`, `rounded-4`.

## Реализованные компоненты

Обязательные:

- `navbar` — единая навигация с активным пунктом и мобильным меню;
- `card` — карточки товаров, категорий, формы заявки и контактов;
- `btn` — `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-light`, размеры `btn-lg`;
- `badge` — «Хит», «Новинка», «Скидка 13%», «Нет в наличии», «В наличии»;
- `alert` — подсказки в каталоге, на странице товара и заявки;
- `modal` — быстрый заказ;
- формы: `form-control`, `form-select`, `input-group`, `form-check`, `form-switch`.

Дополнительные:

- `dropdown` — меню категорий в навбаре;
- `breadcrumb` — хлебные крошки;
- `tabs` — вкладки на странице товара;
- `accordion` — вопросы на страницах товара и контактов;
- `carousel` — отзывы на главной;
- `offcanvas` — фильтр каталога на мобильном экране;
- `toast` — уведомление об отправке формы;
- `list-group` — шаги заказа, отзывы, контакты;
- `table` — `table-striped`, `table-hover`, `table-bordered`, `table-responsive`.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** из `vendor/bootstrap/` вместо CDN.
2. **Дополнительная страница** `contacts.html` с формой обратной связи и FAQ.
3. **Фильтр каталога.** Кнопки-переключатели `btn-check` выбирают категорию,
   `form-switch` скрывает отсутствующие товары, счётчик показывает,
   сколько товаров найдено. Категорию можно открыть ссылкой
   (`catalog.html#beans`) — так работают плитки категорий на главной и меню
   «Категории».
4. **Фильтр на мобильном экране** спрятан в `offcanvas-lg`: на компьютере это
   боковая колонка, которая остаётся видна при прокрутке, на телефоне —
   выезжающая панель.
5. **Варианты карточек:** скидка (зачёркнутая старая цена), «нет в наличии»
   (серое изображение и неактивная кнопка), новинка, хит.
6. **Сценарий заказа:**
   - «Заказать» в любой карточке открывает модальное окно, где уже указан товар;
   - «Оформить заявку» на странице товара открывает `order.html?product=zhernov`
     с выбранным товаром;
   - после отправки появляется `toast`.
7. **Улучшенные формы:**
   - проверка по схеме Bootstrap (`needs-validation`, `was-validated`) с текстом
     ошибки под каждым полем;
   - фокус переходит на первое ошибочное поле;
   - телефон через `input-group` с префиксом `+7` и шаблоном номера;
   - количество с подписью «шт.»;
   - способ получения радиокнопками;
   - товары сгруппированы в `optgroup`.
8. **Страница товара:** вкладки (описание, характеристики, комплектации,
   отзывы), ссылка «32 отзыва» открывает вкладку отзывов, `accordion` с вопросами,
   блок «С этим товаром покупают».
9. **Тема через CSS-переменные Bootstrap** в `custom.css`. Переопределены
   `--bs-primary`, `--bs-dark-rgb`, `--bs-light-rgb`, цвета ссылок и фона,
   переменные кнопок, accordion и фокуса полей. Кофейная палитра
   применяется ко всем компонентам без переписывания их стилей.
10. **Доступность:**
    - ссылка «Перейти к основному содержимому» (`visually-hidden-focusable`);
    - `aria-label` у кнопок без текста;
    - `caption` у таблиц;
    - текст оценки для экранных читалок;
    - карусель без автопрокрутки;
    - учёт `prefers-reduced-motion`.

## Как проверить

1. Открыть `index.html`. Пройти по меню на всех страницах: активный пункт
   подсвечен. Открыть меню «Категории» → «Кофемолки»: каталог показывает
   только кофемолки.
2. В каталоге переключить категории и «Только в наличии»: меняется список
   и счётчик.
3. Нажать «Заказать» у любого товара: в окне указан этот товар. Нажать
   «Отправить» с пустыми полями — под полями появятся ошибки. Заполнить
   (телефон `900 123-45-67`) — окно закроется, появится уведомление.
4. На `product.html` нажать «32 отзыва», переключить вкладки, раскрыть вопросы.
   Нажать «Оформить заявку» — в форме заявки уже выбран товар.
5. На `order.html` и `contacts.html` отправить пустую форму, затем заполненную.
6. В DevTools проверить ширины 375, 768, 1024 и 1440 px. На 375 px меню
   сворачивается в кнопку, фильтр каталога открывается кнопкой «Фильтры
   и категории», горизонтальной прокрутки нет.
