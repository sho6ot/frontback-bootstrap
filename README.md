# Зерно и помол — Bootstrap-версия

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект — учебная версия интернет-магазина кофе и оборудования для заваривания,
разработанная с использованием Bootstrap. Это отдельная реализация той же
предметной области, что и в контрольной работе №1, но на CSS-фреймворке.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap 5.3.8 через CDN (CSS и JS Bundle);
- подключение `css/custom.css` после Bootstrap;
- шапка страницы и Bootstrap-навигация `navbar`;
- hero-блок на сетке: `container-fluid` для фона, `container` + `row` + `col-12 col-lg-6`;
- блок преимуществ: `col-12 col-md-6 col-lg-3`;
- сетка популярных товаров: `col-12 col-md-6 col-lg-4`, промежутки `g-4`;
- подвал страницы на сетке.

## Используемые технологии
